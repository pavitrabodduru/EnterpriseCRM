# Enterprise CRM System

## Overview

The Enterprise CRM System is a web-based application designed to manage customer leads and track sales activities efficiently.

## Features

* Add New Leads
* Delete Leads
* Search Leads
* Lead Status Tracking
* Dashboard Statistics
* Responsive User Interface
* Local Storage Support

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Dashboard Metrics

* Total Leads
* Contacted Leads
* Closed Deals

## Future Enhancements

* Edit Lead Feature
* User Authentication
* Database Integration
* Sales Analytics
